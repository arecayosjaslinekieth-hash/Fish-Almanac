# 🎣 Fish Almanac PH - Beginner's Guide

![Fish Almanac PH](https://via.placeholder.com/1200x400/059669/ffffff?text=Fish+Almanac+PH+%F0%9F%8C%8A%F0%9F%91%8D)

**Real photos + fishing tips for Philippines!** Perfect for beginners.

## 🐟 Features
- **Click any fish photo** → See detailed info + BIG photo
- **Freshwater** (Tilapia, Hito, Carp, Dalag)
- **Saltwater** (Bangus, Maya-maya, Lapu-lapu, Tuna)
- **🇵🇭 PH Favorites** section
- **Animated ocean waves** background
- **Mobile responsive** 📱
- **Zero setup** - just open in browser!

## 🎮 How to Use
1. Click **🏠 Home** or any tab
2. **Click fish photos** for details
3. **Real PH fishing tips** + bait info!
